## 👨‍💻 Sobre mim

Sou um **Analista de TI** e estudante de **Análise e Desenvolvimento de Sistemas (Estácio)**, com forte direcionamento para a área de desenvolvimento de software. Meu foco está na criação de aplicações completas, unindo o **Back-end** robusto com um **Front-end** dinâmico e escalável. 

- 🚀 Atualmente aprofundando meus conhecimentos na stack **Full Stack (React, Node.js, C#, .NET e Java)**.
- 💡 Apaixonado por projetar APIs RESTful e modelar bancos de dados relacionais eficientes (SQL/PostgreSQL).
- 🎓 Embaixador Estudantil do Google, sempre em busca de inovação e excelência.
- 📫 Quer bater um papo sobre tecnologia ou projetos? Me chame no [LinkedIn](https://www.linkedin.com/in/lécio-ferreira-9aaa59280/).
